# 课程实验学习与 Skill 演进记录

本记录只整理已经开展的课程学习与技能变化。每次形成新经验时按日期追加，不预写未开展学习的结果。

## 演进方法

完成一项实验后，在本节之后追加一条记录，不覆盖已发生的历史。每条记录写明：

- 实验主题、日期和当前状态；
- 本次实际收到或生成的关键证据；
- 从本次实验提炼出的、对后续学习有用的方法或概念；
- 因此修改了 Skill 的哪个部分；
- 尚缺的实测、截图、说明或交付物。

只记录已发生的学习变化。学习尚未完成时标为“进行中”或“待补证据”。
