## 问题二

> 问：要使用好AI工具，写好prompt(提示词)是非常重要的，提示词至少要有角色、上下文、任务。专家们提供了很多结构化提示词的框架，比如ICDO，BROKE，CRISP等，你知道哪些提示词框架？如果不知道，通过搜索工具或者AI工具学习一个。Markdown是结构化prompt的好方法，请为你学习的prompt框架使用Markdown格式设计一个通用模板

- 回答：以上的提示词框架我都不太系统性的了解过，但是在询问AI关于提示词框架后，我发现我在实际使用AI的过程中常常见到的就是CRISP框架；
- 其他的提示词框架还有CO-STAR/RISEN/RTF等，我今后会多有意识的使用CRISP/CRISPE框架及其他拓展；
- 设计的通用模板如下

```markdown
# Context
项目背景

# Goal
最终完成目标

# Inputs
可以使用哪些信息、文件、代码等材料

# Requirements
必须满足的要求

# Process
应该按照何种步骤完成

# Output
最终输出和交付要求

# Validation
对任务是否正确完成的判断方法

```
